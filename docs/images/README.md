# Setup images

- `telegram-login.png` is an actual capture of the unauthenticated page at
  https://my.telegram.org/auth, taken on 2026-10-06. No number or code was entered.
- `telegram-api-form.png` and `telegram-api-credentials.png` are clearly labeled
  illustrations with example fields and placeholders. They are not screenshots
  of an authenticated Telegram account. The current site's fields and validation
  rules take precedence.

The images contain no account credentials, personal messages, entered personal
phone numbers or session data. The sample phone string in the public login
capture is the site's placeholder. The illustration title uses “Unofficial” to
avoid suggesting an official Telegram product.
