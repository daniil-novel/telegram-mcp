Согласие не переносится между чатами. Рекомендуем учитывать его отзыв, чтобы согласие оставалось действующим.

Наша рекомендация: не считайте API ID, доступ к аккаунту, локальный inference или обезличивание разрешением на ИИ-обработку. Утилита не собирает и не проверяет такие согласия. Техническая совместимость с Codex не означает разрешения платформы. Это не вывод о незаконности любого ИИ-inference: нужны конкретный контекст и анализ применимых условий.

Ещё два пробела требуют проверки по [API Terms §§1.4 и 3.3](https://core.telegram.org/api/terms): утилита не отправляет обновления read/typing/presence и не поддерживает sponsored messages каналов.
